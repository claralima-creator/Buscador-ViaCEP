# Buscador ViaCEP

Aplicação web desenvolvida para praticar **JavaScript assíncrono**, utilizando a API do [ViaCEP](https://viacep.com.br/).

O projeto permite consultar um CEP e preencher automaticamente os dados do endereço.

## Funcionalidades

*  Consulta de CEP através da API ViaCEP
*  Limpeza automática de caracteres não numéricos
*  Validação da quantidade de dígitos do CEP
*  Preenchimento automático de:

  * Cidade
  * Estado
  * Bairro
  * Logradouro
*  Mensagem de carregamento durante a consulta
*  Desativação dos campos enquanto a busca está sendo realizada
*  Tratamento de CEP inexistente
*  Tratamento de erros na requisição
*  Interface estilizada com CSS

##  Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Fetch API
* Promises
* Async/Await
* API ViaCEP

##  O que pratiquei neste projeto

Este projeto foi desenvolvido como prática dos conceitos de JavaScript assíncrono, principalmente:

* `fetch()`
* `Promise`
* `async/await`
* `try/catch`
* Manipulação do DOM
* Eventos com `addEventListener`
* Validação e tratamento de dados
* Manipulação de formulários
* Tratamento de erros HTTP
